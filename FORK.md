# Отличия сборки andromanpro

Сборка основана на [CodePilot1C](https://github.com/ondysss/codepilot1c-edt) и распространяется отдельно от оригинала. Этот документ описывает возможности выпуска **1.3.9.20261031-0636**.

## Возможности форка

| Возможность | Что доступно |
|---|---|
| Командный интерфейс | `inspect_command_interface` и `mutate_command_interface`: чтение, очистка повреждённых записей, размещение и порядок существующих команд через модель EDT |
| Обновление расширения | `edt_update_extension`: полное обновление одного расширения с проверкой цели и конечного результата |
| Подключение серверной ИБ | `connect_infobase` с `kind=server`: привязка существующей клиент-серверной базы к проекту |
| Контексты расширений | `edt_project_context`: чтение и настройка контекстов через отдельно установленный EDT Extension Tweaks |
| Снятие регистрации проекта | `workspace_remove_project`: удаление проекта из рабочей области с сохранением исходников и проверкой зависимостей |
| СКД | Чтение и изменение схемы с учётом имён и порядка элементов формата платформы |
| Ограничения доступа | Чтение и изменение ограничений доступа к записям и полям в штатной модели прав |
| Картинка подсистемы | Назначение, замена и снятие существующей общей картинки |
| Формы и метаданные | Исправления серверных обработчиков, свойств форм, предопределённых элементов, расписаний, составных типов и квалификаторов |
| Справка инструмента | `discover_tools` с `tool_name`: описание, JSON-схема и признаки мутации/подтверждения одного инструмента |

Часть исправлений также доступна в оригинале. Совпадение номера линии `1.3.9` не означает полного совпадения сборок.

## Совместимость и ограничения

- Проверенная среда: **1C:EDT 2025.2.3 / Java 17 / Windows x86-64**. Совместимость с EDT 2026.2.2 / Java 25 и другими ОС для этого ZIP не подтверждена.
- Для `edt_project_context` нужен отдельный плагин EDT Extension Tweaks (`ru.xelgo.edt.contextlinks.ui`). Он не входит в поставку.
- `workspace_remove_project` сохраняет файлы проекта и не удаляет расширение из информационной базы.
- Операции GSD с защищённым доступом к файловой системе ограничены возможностями ОС и Java. На Windows такие операции могут возвращать `unsupported`.
- Защита объектов поставки с запретом изменений проверена тестами; её срабатывание на таком объекте в живой базе не подтверждено.
- После изменения метаданных следует проверить результат чтением модели, диагностикой EDT и, когда это существенно, запуском 1С.
