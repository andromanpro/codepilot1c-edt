# Чем этот форк отличается от исходного проекта

Форк [ondysss/codepilot1c-edt](https://github.com/ondysss/codepilot1c-edt). Исходный проект —
MCP-сервер внутри 1C:EDT, дающий ИИ-агенту семантический доступ к проекту 1С. Здесь — то же
самое плюс слой, выросший из ежедневной работы с расширениями, поставками и живыми базами.

Общее правило форка: **инструмент, который врёт, — это задача, а не препятствие.** Поэтому
почти каждый пункт ниже начинался с того, что инструмент молча сделал не то, и чинился в
исходнике, а не обходился в промпте. Часть исправлений отдана в исходный проект PR-ами.

## Добавленные инструменты

| Инструмент | Зачем |
|---|---|
| `query_event_log` | Журнал регистрации файловой ИБ прямо из MCP: собственный разбор `.lgf`/`.lgp` без запуска 1С. Достаёт ошибки, невидимые в зелёном отчёте тестов |
| `run_bsl_snippet` | Выполнение произвольного BSL внутри инфобазы — проверка гипотезы на реальных данных без сборки обработки |
| `change_scope_guard` | Снимок → мутация → сверка: набор изменённых файлов обязан совпасть с заявленным намерением. Ловит и правку вне декларации, и заявленный-но-нетронутый файл |
| `rename_metadata` | Переименование объекта метаданных через модель EDT |
| `extension_manage` | Управление расширением, включая `adopt_dependencies` (адопция без «свиты» из сотни зависимостей) и `prune` |

## Гейты молчаливых отказов платформы

Класс дефектов, где платформа не выдаёт ни ошибки, ни предупреждения, а последствия всплывают
через месяцы. Для агента это опаснее всего: нет сообщения об ошибке — значит «получилось».

- **Замок поддержки.** Мутация объекта типовой конфигурации с запретом изменений отклоняется
  кодом `SUPPORTED_OBJECT_LOCKED` во всех мутирующих инструментах. Осознанный обход — явный
  параметр `allow_supported_object_edit` (решение человека, не умолчание агента).
- **Целостность uuid.** `edt_diagnostics {command: "uuid_check"}` — глобальная уникальность всех
  uuid-атрибутов по исходникам проекта. Гонять после массовой генерации, адопции и слияния выгрузок.
- **Роль — ссылка, а не строка.** Присваивание строки реквизиту «Роль» даёт пустую ссылку, и роли
  профиля молча теряются. Инструменты записи BSL предупреждают и подсказывают рецепт.

Гейты закрыты 17 юнит-тестами; каждый проверен мутацией — тест обязан краснеть, когда гейт
сломан. Прогон без Tycho: `bash scripts/run-gate-eval.sh`.

## Исправления поведения

- **Упавшее обновление ИБ больше не отдаёт `DONE`.** Раньше отказ прятался внутри поля результата,
  вызывающий видел успех и продолжал работать со старой конфигурацией.
- **Кто держит информационную базу.** `update_infobase` возвращает список процессов-держателей:
  забытый тонкий клиент или тест-раннер тихо отменял обновление.
- **Инспектор процессов на Windows** отдавал пустой список (сбор шёл юниксовым способом).
- **Схемы компоновки данных** писались в собственном диалекте XML: платформа такой файл не читала,
  а выгрузка конфигурации падала целиком из-за одного отчёта.
- Составные типы, синонимы стандартных реквизитов, FQN дочерних объектов в правах ролей, поиск
  с ограничением по проекту и расширениям, режим блокировок при создании регистров.

## Совместимость и запуск

- 1C:EDT **2025.2.3**, Java 17. Сборка: `mvn -DskipTests -pl '!:com.codepilot1c.core.tests' package`.
- MCP слушает `127.0.0.1:8766` (Bearer-токен выдаётся плагином и виден в настройках EDT).
- Установка — как в основном README: update site или ZIP, но артефакт брать из выпусков этого форка.
