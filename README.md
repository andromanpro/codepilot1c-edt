# CodePilot1C — сборка andromanpro

Форк [ondysss/codepilot1c-edt](https://github.com/ondysss/codepilot1c-edt) с дополнительными MCP-инструментами и исправлениями для разработки конфигураций и расширений 1С.

**[Скачать последний релиз](https://github.com/andromanpro/codepilot1c-edt/releases/latest)** · [Отличия форка](FORK.md) · [Изменения выпуска](docs/release-notes/fork-2026-10-31.md)

## Совместимость

Этот выпуск проверен на **1C:EDT 2025.2.3 / Java 17 / Windows x86-64**. Линия плагина — `1.3.9`. Совместимость ZIP с EDT 2026.2.2 / Java 25 и другими ОС пока не подтверждена.

## Установка нашей сборки

1. Откройте [Releases этого форка](https://github.com/andromanpro/codepilot1c-edt/releases/latest).
2. В **Assets** скачайте `com.codepilot1c.update-<версия>.zip`. Архивы **Source code** содержат исходники и не устанавливают плагин.
3. В EDT откройте **Справка → Установить новое ПО… → Добавить… → Архив…** (`Help → Install New Software… → Add… → Archive…`).
4. Выберите ZIP, отметьте **1C Copilot**, пройдите мастер и перезапустите EDT. При запросе доверия подтвердите выбранный плагин.
5. В сведениях об установленном ПО сверьте версию с релизом.

**Сайт `ondysss.github.io/codepilot1c-edt/` устанавливает оригинальный CodePilot.** Для этой сборки нужен ZIP из нашего релиза. Собственный сетевой update site форка пока не опубликован.

Оригинал и форк используют одинаковые идентификаторы Eclipse-бандлов: это альтернативные сборки одного плагина. Если мастер не разрешает замену версии, сохраните прежний ZIP, удалите `1C Copilot` через **Справка → О программе → Сведения об установке → Установленное ПО**, перезапустите EDT и установите ZIP форка. Для отката используйте сохранённый архив. Не копируйте отдельные JAR поверх работающей EDT.

## Подключение MCP

В настройках CodePilot включите MCP Host, проверьте HTTP endpoint и скопируйте Bearer-токен. Обычная рабочая настройка форка — `http://127.0.0.1:8766/mcp`; фактический порт и токен берите из своей EDT.

Внешнему клиенту нужны URL и заголовок `Authorization: Bearer <token>`. Не публикуйте токен и ключи LLM. При работе через внешний MCP модель предоставляет ваш клиент.

## Основные отличия

- Командный интерфейс через BM: чтение, очистка повреждённых записей, размещение и порядок команд.
- Полное обновление одного расширения через `edt_update_extension` с проверкой цели и конечного результата.
- Привязка существующей клиент-серверной ИБ к проекту, контексты расширений и снятие регистрации проекта с сохранением файлов.
- СКД в формате платформы, ограничения доступа к записям и полям, назначение общей картинки подсистеме.
- Исправления создания и изменения форм, типов, расписаний и предопределённых элементов.
- Описание и JSON-схема отдельного инструмента по запросу.

Подробности и ограничения — в [FORK.md](FORK.md).

## Справка по инструментам

Раскрыть категорию: `discover_tools {"category":"forms"}`.

Получить описание и полную JSON-схему одного инструмента: `discover_tools {"tool_name":"mutate_form_model"}`. Передайте ровно один из `category` и `tool_name`. Справка берётся из действующего реестра, не выполняет целевой инструмент и не раскрывает всю категорию. Протокол `edt_validate_request` → мутация с актуальным `validation_token` → независимое чтение результата сохраняется.

## Сборка из исходников

Нужны JDK 17, Maven и EDT 2025.2.3. Сборку выполняйте из чистой копии исходников.

    mvn -DskipTests -Dedt.home="<каталог EDT 2025.2.3>" -pl '!:com.codepilot1c.core.tests' package

Готовый ZIP находится в `repositories/com.codepilot1c.update/target/`. Команда пропускает тесты; ограничения выпуска описаны в [примечаниях к релизу](docs/release-notes/fork-2026-10-31.md).
