Версия **1.3.9.20261031-0636** для **EDT 2025.2.3 / Java 17 / Windows**. Установка — update-site ZIP из [GitHub Releases](https://github.com/andromanpro/codepilot1c-edt/releases/tag/v1.3.9.20261031-0636).

## Что изменилось

- Включены накопленные исправления и инструменты командного интерфейса, обновления расширений, подключения серверной ИБ, RLS, форм, СКД, типов и расписаний. [Подробности](../../FORK.md).
- В `discover_tools` добавлена справка по точному `tool_name`: описание, JSON-схема и признаки мутации/подтверждения, без выполнения целевого инструмента.
- Из оригинала адресно перенесено [удаление Eclipse Terminal](https://github.com/ondysss/codepilot1c-edt/commit/9527d4b3db53e38909c097416542d20f4c8e309f): прежний UI-бандл не разрешался в чистой EDT без дополнительно установленного Terminal. Зависимости и команда удалены, самостоятельный CLI сохранён.
- `README` описывает установку нашего ZIP и явно отличает его от сайта обновлений оригинала.
- Добавлена [оценка перехода на EDT 2026.2.2 и выборочного переноса EDT-MCP](../research/edt-and-edt-mcp-2026-10-31.md).

## Проверка

Окончательный ZIP собран полным Tycho-реактором из чистого `git archive` публичного исходного коммита `ef5a17ed`, без накопленных `target/classes`. Тестовый бандл `core.tests` проверялся отдельными прогонами.

- Целевой набор против окончательных классов: **14/14** — справка, прежнее раскрытие категории, зависимости feature/UI и HTTP health.
- Строгие JSON-схемы всех инструментов против точного ZIP: **7/7**.
- Контракты удаления Eclipse Terminal: **4/4**.
- Отрицательный контроль: те же 6 новых тестов на прежнем ядре дают 4 ожидаемых падения; на новом проходят все 6.
- Общий сравнительный набор: **2195 тестов** на исходной интеграции и на окончательных классах, **57 одинаковых падений**, новых упавших имён нет. Передан предусмотренный тестовым POM параметр `core.bundle.path`; полный OSGi-набор полностью зелёным не объявляется.
- Неизменённый `EdtUpdateInfobaseToolStandaloneTest` исключён из компиляции общего набора из-за несовместимого API локального SDK EDT 2025.2.3.
- Отдельные runtime-модули: **114 тестов**, одно падение `portablePathsKeepPlatformConventions` на сравнении POSIX-пути с путём Windows, два пропуска. Исходник этого теста и runtime-код не менялись в нашем выпуске; результат не выдаётся за полностью зелёный.
- Точный ZIP запущен в изолированной headless-EDT 2025.2.3 с отдельной конфигурацией и пустой рабочей областью: MCP initialize, tools/list, реальный HTTP-вызов новой справки и отказ для неизвестного имени прошли. В журнале успешного прогона нет записей уровня ERROR. Это проверка запуска/контракта, а не живая проверка каждой мутации и отрисовки GUI.

Контрольная сумма ZIP и краткий машиночитаемый отчёт поставляются как `SHA256SUMS.txt` и `verification.json`. Последующие изменения документации не меняют файлы сборки исходного коммита.

EDT 2026.2.2 / Java 25 пока не проверены. Реализация защиты замкнутых объектов поставки покрыта тестами; живое срабатывание на объекте с запретом изменений ранее не было подтверждено. Новые сценарии не объявляются проверенными на всех версиях EDT.
