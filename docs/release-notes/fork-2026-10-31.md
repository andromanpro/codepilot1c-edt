# CodePilot1C — сборка 1.3.9.20261031-0636

Выпуск для **1C:EDT 2025.2.3 / Java 17 / Windows x86-64**.

## Изменения

- Добавлены инструменты чтения и изменения командного интерфейса, обновления отдельного расширения, подключения серверной ИБ и снятия регистрации проекта с сохранением файлов.
- Включены доработки СКД, ограничений доступа, форм, типов, расписаний и предопределённых элементов. [Возможности и ограничения](../../FORK.md).
- `discover_tools` принимает `tool_name` и возвращает описание и JSON-схему отдельного инструмента без его выполнения.
- Удалена ненужная зависимость интерфейса плагина от Eclipse Terminal, мешавшая запуску в чистой EDT.

## Установка

Скачайте `com.codepilot1c.update-1.3.9.20261031-0636.zip` из [Assets релиза](https://github.com/andromanpro/codepilot1c-edt/releases/tag/v1.3.9.20261031-0636). В EDT: **Справка → Установить новое ПО… → Добавить… → Архив…**. Выберите ZIP и `1C Copilot`, завершите установку и перезапустите EDT. [Полная инструкция](../../README.md#установка-нашей-сборки).

Архивы **Source code** содержат исходники. Для установки плагина используйте update-site ZIP. Контрольная сумма находится в `SHA256SUMS.txt`.

## Проверка и ограничения

Проверены сборка, запуск плагина и основные HTTP-вызовы MCP, включая новую справку инструмента. В общем наборе тестов остаются известные сбои; выпуск не заявляется как прошедший все тесты. Проверка не охватывает все изменения метаданных и все сценарии интерфейса 1С.

Совместимость этого ZIP с EDT 2026.2.2 / Java 25 и другими ОС не подтверждена. Ограничения отдельных инструментов перечислены в [FORK.md](../../FORK.md#совместимость-и-ограничения).
