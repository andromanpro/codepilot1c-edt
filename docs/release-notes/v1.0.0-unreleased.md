# CodePilot1C 1.0.0 — не выпущено

**Статус:** версия не выпущена и не опубликована.

## Несовместимая граница OSGi API

Версия 1.0.0 устанавливает намеренную несовместимую границу публичного OSGi API. Удалённая compatibility surface включает:

- `ProviderContextResolver`;
- API backend-оптимизаций в `ProviderCapabilities` и `ProviderUtils`;
- provider state в `ToolSurfaceContext`;
- прежний contributor с backend-ориентированным именем.

Внешние overlay bundles должны быть мигрированы и повторно скомпилированы против API 1.0.0. Compatibility shims для удалённых API не предоставляются.

При этом сохранены generic OpenAI-compatible transport и content fallback, а также внешние Qwen eval/runner assets.

Update site в рамках этой задачи не публиковался.
