# CodePilot1C 1.3.4

Patch-релиз исправляет неполное сканирование метаданных открытых EDT-проектов инструментом
`scan_metadata_index`.

## Исправления

- Typed-коллекции `Configuration` теперь сканируются всегда, а reflective-обход используется как
  дополнительный источник с общей дедупликацией результатов.
- FQN родительского top BM-объекта больше не используется как FQN нетопового элемента метаданных.
  Для такого элемента формируется стабильный FQN вида `Kind.Name`.
- Добавлены регрессионные тесты для частичного reflective-результата, дедупликации и правил
  `BmObjectHelper` при работе с top/non-top объектами.

## Проверка

- Полный Tycho reactor и набор unit-тестов проходят на target platform EDT `2025.2.3+30`.
- Update site: <https://ondysss.github.io/codepilot1c-edt/>.
