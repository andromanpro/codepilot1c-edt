# CodePilot1C 1.3.5

## `scan_metadata_index` pagination

- Added zero-based `offset` pagination while preserving `offset=0`, `limit=200` defaults and
  the existing `limit` maximum of `1000`.
- Responses now include `offset` and `nextOffset` together with `total`, `returned`, and
  `hasMore`. When `hasMore=true`, pass `nextOffset` as the next request's `offset` while keeping
  the same project and filters.
- Index entries use a deterministic total ordering by kind, name, and FQN before pagination.
- Invalid, negative, fractional, or overflowing pagination values fail with `INVALID_ARGUMENT`.
  An `offset` greater than or equal to `total` returns an empty page.

Example next-page request:

```json
{
  "projectName": "DO",
  "scope": "all",
  "limit": 200,
  "offset": 200
}
```

Pagination is not a stored snapshot. If EDT metadata changes during a full traversal, restart
from `offset=0` for a consistent view.
