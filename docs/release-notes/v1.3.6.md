# CodePilot1C 1.3.6

## Unicode BSL structure and path-qualified hierarchy

- `edt_get_module_structure` now recognizes case-insensitive Russian BSL declarations such as
  `Функция`, `Процедура`, `#Область`, and `#КонецОбласти`.
- `edt_get_method_call_hierarchy` accepts an optional backward-compatible `modulePath` selector.
  Pass the `file_path` returned by `edt_list_modules` when duplicate module FQNs exist.
- Method identity and hierarchy edges are keyed by module file path plus method name. Unqualified
  local calls prefer methods in the same module, so duplicate FQNs no longer merge their methods
  or local edges.
- A legacy `methodFqn` that resolves to more than one module now returns `INVALID_ARGUMENT` with
  an instruction to pass `modulePath`, instead of silently choosing one module.
- `edt_get_module_structure.moduleFqn` continues to accept either an FQN or a path; its schema now
  recommends the path form for duplicate FQNs.

Example disambiguated hierarchy request:

```json
{
  "projectName": "ДО.Артель",
  "methodFqn": "Catalog.Тест.Module.Обработать",
  "modulePath": "Catalogs/Тест/Forms/Форма1/Module.bsl",
  "direction": "both",
  "depth": 1
}
```
