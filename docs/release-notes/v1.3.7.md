# CodePilot1C 1.3.7

## Fast, path-qualified BSL call graph and exact source ranges

- New read-only `edt_get_project_call_graph` builds the project code index once and returns
  deterministic direct call edges. Every source and target contains `file_path`, `method_name`,
  and `method_fqn`, so duplicate module FQNs do not merge graph nodes.
- Pass optional `modulePath` to select edges whose source belongs to one module while retaining
  path-qualified targets. Without it, the tool returns the whole project graph.
- Ambiguous or unresolved calls are not guessed into edges. They are reported in
  `unresolved_calls` with a reason and candidate count.
- `edt_get_method_call_hierarchy` now uses the same single-pass index and avoids the previous
  quadratic scan on projects with large BSL modules.
- The parser switched to horizontal whitespace and dedicated end declarations. A known Axiom
  JDK 25 word-boundary incompatibility still causes fallback end ranges for Russian declarations
  in this release; this is corrected in 1.3.8.

Example module graph request:

```json
{
  "projectName": "ДО.Артель",
  "modulePath": "HTTPServices/ар_аи_health/Module.bsl"
}
```
