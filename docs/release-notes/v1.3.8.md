# CodePilot1C 1.3.8

## Exact Unicode BSL source ranges on EDT JDK 25

- `edt_get_module_structure` now reports exact 1-based region and method ranges in the EDT
  runtime, including Russian `КонецФункции`, `КонецПроцедуры`, and `#КонецОбласти` declarations.
- End-declaration parsing no longer relies on a regex word boundary after Cyrillic text. It uses
  an explicit delimiter lookahead compatible with EDT's Axiom JDK 25 runtime.
- Terminators with semicolons, trailing horizontal whitespace/comments, and CRLF source input are
  covered by regression tests.
- The fast, path-qualified `edt_get_project_call_graph` and hierarchy implementation introduced
  in 1.3.7 is unchanged.

Update site: <https://ondysss.github.io/codepilot1c-edt/>
